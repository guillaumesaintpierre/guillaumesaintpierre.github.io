This independent demo explores one narrow problem in football analytics: finding corner kicks that satisfy transparent spatial and temporal rules, using public event data rather than proprietary REPLAY tracking.

ENGINEERING NOTE 01

01 — Data and features

The pipeline downloads StatsBomb Open Data, extracts corner events and labels side, short/long delivery and target zone. It identifies whether a same-team shot occurred within 10 seconds in the same possession and sums qualifying expected-goals values.

The labels are interpretable deterministic thresholds, not fitted professional scouting metrics. Event data describes on-ball actions but does not reconstruct player positioning between events.

ENGINEERING NOTE 02

02 — Search to video

A small controlled English/French parser converts a request into explicit filters. Matching events can be exported as timestamped JSON windows, then optionally synchronized with legally obtained footage via first- and second-half kickoff offsets and rendered as MP4 clips using FFmpeg.

The modular Python implementation is covered by tests for event flattening, rule assignment, parsing, filtering, exports and time alignment. This personal demo is not part of the private EPFL AI Team REPLAY codebase.
