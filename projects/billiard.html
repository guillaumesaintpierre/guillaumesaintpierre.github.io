MY ROLE

Collaborative mechanical-engineering / programming project

We investigated how to transform raw image sequences into a structured description of a three-cushion billiards shot, including ball positions, trajectories, cushion contacts and a final score sheet.

ENGINEERING NOTE 01

01 — End-to-end architecture

LabVIEW loads image frames, defines the billiard area and orchestrates processing. A standalone C detector locates the red, yellow and white balls from raw pixel data. MATLAB cleans trajectories, identifies movement and cushion-contact events, applies the three-cushion rules and generates a PDF score sheet plus a structured summary.

The key difficulty is not just recognizing colours in one frame, but maintaining useful trajectories when detections are missing, noisy or physically inconsistent.

ENGINEERING NOTE 02

02 — Detection, integral images and event logic

The C program extracts RGB channels, generates colour masks and scores candidate ball positions. A summed-area table (integral image) allows each rectangular detection-window sum to be computed from four lookup values after a linear preprocessing pass. This avoids repeatedly summing every pixel inside a sliding window.

sum(region) = D − B − C + A four integral-image corner values

The MATLAB stage marks missing observations, removes trajectory outliers, estimates travelled distances, identifies the first moving ball and counts cushion touches between relevant ball-contact events. The rules-based decision is exported as a visual and machine-readable result.

ENGINEERING NOTE 03

03 — Testing and limitations

The repository includes C tests for known-colour positions, malformed pixmap inputs, invalid dimensions and the missing-ball case; GitHub Actions repeats the build and test suite. This is a particularly useful software engineering lesson: a physically intuitive computer-vision pipeline still needs formal input validation and reproducible tests.

The C component can be tested independently, while a complete run requires compatible LabVIEW and MATLAB installations and a suitable recorded frame sequence. Ball occlusions and rule inference remain limitations. A representative original score sheet is linked in the repository.
