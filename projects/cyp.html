Machine learning / ENGINEERING CASE STUDY 08

Predicting CYP Inhibition

A reproducible baseline for molecular property prediction with LightGBM and RDKit descriptors.

2026 · DTU Deep Learning 02456Baseline model and validation
IN THIS STUDY
Problem and dataBaseline modelValidation and lessons
MY ROLE

Molecular descriptors, LightGBM baselines, hyperparameter studies, validation and classification diagnostics, within a group project.

In molecular ML, strong evaluation practices can matter as much as model complexity. I developed and tested a transparent baseline before comparing it with more complex approaches.

01 / PROBLEM

Problem and data

The DTU project studies prediction of cytochrome P450 (CYP) inhibition from molecular structures. The working setup includes four continuous pIC50 targets (CYP1A2, CYP2C9, CYP2D6 and CYP3A4) and two time-dependent inhibition classification tasks (CYP2D6 and CYP3A4).

A baseline is useful as a reproducible performance reference and helps identify challenges such as missing labels, uneven task difficulty and class imbalance.

02 / METHOD

LightGBM + molecular descriptors

Used Morgan fingerprints together with RDKit molecular descriptors as structured model features, trained task-specific LightGBM estimators and compared learning rate, tree complexity and minimum leaf samples. The project has distinct training and validation splits; test results should not be inferred from validation metrics.

Experiments were tracked through saved configuration files and validation JSON outputs so model variants could be compared consistently.

03 / EVALUATION

Validation and lessons

Evaluated regression through errors and explanatory metrics and classification using discriminative and threshold-dependent metrics. One important diagnostic was the CYP2D6 classifier predicting no positive cases at its default decision threshold, despite nontrivial ranking capability. This illustrates why raw accuracy or AUROC alone is insufficient for an imbalanced assay.

Scope: This case study describes the implemented baseline and its validation work, not a validated new state-of-the-art result or a final ensemble system.
